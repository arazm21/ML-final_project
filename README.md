### ARIMA/SARIMA/SARIMAX

ეს იყო პირველი მოდელი, რომელზეც გადავწყვიტე მემუშავა. მალე მივხვდი, რომ ARIMA არ 
ივარგებდა ამ დავალებისთვის, რადგან აუცილებელია სეზონურობის დანახვა, რაც ARIMA-ს არ შეუძლია,
შესაბამისად გადავედი SARIMA-ზე. SARIMA-მ უკეთესი შედეგი მომცა და მონაცემების უმეტესობაზე 
კარგად იჯდა, თუმცა მონაცემთა დაახლოებით 20%-ზე ირეოდა და ან სულ 0 იყო, ან წრფე ანდა
შემთხვევითად 100-ჯერ უფრო დიდ შედეგს აბრუნებდა. ამ პრობლემებზე გაბრაზებულმა გადავწყვიტე,
გადავსულიყავი პროფეტზე და ამ მოდელებს შემდგომ აღარ მიბუბრუნდი. SARIMAX-ი
კიდებ უკეთესი იყო, მაგრამ მასაც ზუსტად იგივე პრობლემები სჭირდა, შესაბამისად შევეშვი.
